# Getting help

Start with the [README](README.md), [local startup guide](docs/healthbox/QUICK_START.md)
and [known issues](docs/healthbox/KNOWN_ISSUES.md).

For ordinary questions or bugs, use the new HealthBox repository's issue forms.
Include the source revision, a generic environment description and minimal
steps using synthetic data. Do not send real reports, patient screenshots,
runtime databases, backups, credentials, HAR files or raw production logs.

Security/privacy issues follow [SECURITY.md](SECURITY.md), not a public
reproduction containing sensitive details. Private reporting must be configured
by the repository owner; no personal email address is supplied in this snapshot.

Support is best effort, without a response-time guarantee. This project is not
medical care, an emergency channel or an approved production health service.
