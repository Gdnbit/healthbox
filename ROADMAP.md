# HealthBox roadmap

This roadmap is a direction, not a delivery promise. The current product is an
experimental source preview; no stable public service or clinical validation
is implied. See [known issues](docs/healthbox/KNOWN_ISSUES.md).

## Source disclosure

- Keep private history, credentials and health records outside public Git.
- Preserve upstream attribution and per-file distribution modification notices.
- Use original minimal catalogs and synthetic-only tests and examples.
- Establish a new public repository only with owner approval and a reviewed Git identity.

## Reliability before real records

- Resolve dependency risks and complete the retained test/coverage gates.
- Verify fresh installation, migrations and full database/file restoration.
- Improve report-layout coverage, error recovery, authorization and audit tests.
- Verify phone/desktop workflows and make accessibility and export behavior consistent.

## Later capabilities

- Expand indicator matching only with licensed, traceable reference data.
- Evaluate real read-only AI integrations and source-grounded answer quality.
- Add evidence-versioned screening education without disease-free guarantees.
- Improve deployment documentation and operational recovery.

Report reproducible synthetic cases rather than attaching real medical records.
