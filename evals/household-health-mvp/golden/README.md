# 黄金输出策略

当前黄金输出只来自完全虚构的成员、报告和指标。私有暂存中的个人资料不是自动化黄金答案，也不得复制到本目录。

在真实导入前，浏览器端到端黄金流程必须覆盖：原件保存、候选编辑、接受/忽略、重复预览、事务提交、来源回跳、家庭可视化、结构化导出和受保护回滚。叙述型健康背景另建独立规格与虚构黄金夹具。

管理员恢复命令的机器可读契约见 `admin-recovery-contract.json`。该契约固定 `household-admin-recovery@1.0.0` 的成功字段、禁止输出字段和事务/唯一管理员/MFA/会话不变量；测试与隔离 PostgreSQL 演练只使用虚构账号，不接触线上数据库。

受邀成员首次登录时的版本化说明与确认门禁见 `privacy-consent-contract.json`。该契约固定强制改密优先级、确认前的受限会话、唯一管理员全局读取与组内结构化互见告知、外部处理排除、追加式决定和旧版本失败关闭。

本人隐私与访问透明度见 `privacy-access-contract.json`。该契约固定当前相互可见范围、唯一管理员全局读取提示、本人专用访问记录、普通成员标签、旧记录完整性说明，以及不得返回健康值、原始审计元数据、内部组和账号技术标识的边界。

本人数据权利请求见 `privacy-rights-request-contract.json`。该契约固定本人专属范围、请求类型、幂等、追加式状态、版本化内部目标期限、独立处理证据和删除/停止处理失败关闭；请求本身不直接修改健康数据、共享、账号或存储。

本人 AI 资料包见 `ai-handoff-contract.json`。当前只有固定 `recent_changes` / “最近有哪些变化？”可调用站内服务；任意非规范文本在提供方调用/历史保存前拒绝。就医前问题、术语和自定义自由文本只在本机生成并主动复制资料包。请求最多保留 200 条记录并披露总数和省略数；实际模型 ID 不向成员 capability、回答、历史或成员成功/删除审计暴露；共享档案禁止生成、复制和站内调用。

本人站内最近变化见 `local-ai-qa-contract.json`。本地提供方回答只有通过严格结构、引用白名单、`household-ai-answer@1.1.0` 的逐记录 `R#=<主值><单位>` 显式绑定、只读和已知安全门禁后才展示并进入独立 AI 历史；双值记录必须绑定主值、辅助值和单位。仅列 citation、日期/计数巧合或另一记录的相同数值不能通过。服务器固定追加范围、非诊断/不保证安全和跨机构可比性说明，未校验响应不展示、不保存。合同固定 200 条记录、24,000 输入字符、256,000 响应字节和 800 输出 tokens 上限，且不把通过门禁表述为医学正确。

唯一管理员 AI 配置见 `ai-provider-admin-contract.json`。网页只配置模式、家庭服务器 endpoint 和模型 ID，API key 只在服务器 Secret；“填入本机地址”只填写未保存的 Ollama-compatible endpoint，不推荐或预填模型，也不执行安装/启动/保存/启用。每个 local 修订须通过固定虚构连接测试：修订绑定 endpoint/model，服务器指纹绑定 `health-ai-provider-verification@3`、`household-ai-answer@1.1.0` 和 API key，因此合同、模板、配置或服务器密钥变化都会使旧验证失效。`off` 对新请求立即生效，但不承诺中止已进入本地 provider 的请求。`dynamic_test` 仅在双门禁全虚构实例运行且明确为非模型；当前隔离候选正使用该非模型 oracle，尚无本机模型通过 1.1.0 门禁。服务器为成功回答固定追加跨机构、检测方法或参考范围可能不可直接比较的局限。

本人回答历史见 `ai-answer-history-contract.json`。历史保存经校验的提供方回答、服务器固定说明、提供方/处理模式/测试标记和引用快照，不保存未校验原始响应；每次打开按当前权限、日期、值、单位和状态重验引用。

本人 AI 请求门禁见 `ai-request-guard-contract.json`。合同固定必填幂等请求头、用户/主体/规范载荷绑定、成功/在途/失败/删除/遗留请求重放语义、默认每用户 600 秒 6 次与单在途预算、账本最小化字段，以及 SQLite 顺序合同和 PostgreSQL 两会话并发证据边界。

数据流完整性见 `dataflow-integrity-contract.json`。家庭模式禁用旧方向性共享授权，数值与显示单位必须成对转换；Vite 由 `VITE_DEV_PROXY_TARGET` 选择开发后端，已经运行的 4173 进程重启并指向当前源码后端前不得算联通证据。

正式导入检验的不可变修订契约见 `formal-metric-revision-contract.json`。该契约固定 `household-formal-metric-revision@1.0.0` 的初始版本、只追加历史、本人权限、完整快照、乐观并发、幂等重放、通用改删/回滚保护、最小审计和完整归档不变量。

六账号、多组隔离和合成报告全生命周期见 `synthetic-six-account-e2e-contract.json`。该契约用 A—F 固定唯一管理员、三个重叠共享组、普通成员可见矩阵、跨组 404、共享面板禁止字段，以及“原件—解析候选—复核—提交—趋势—导出—撤回/恢复”的最终计数和安全边界。

稳定备份恢复副本上的迁移往返见 `restored-backup-migration-rehearsal-contract.json`。该契约固定内部网络/无主机端口隔离、基线行数摘要、完整升级—应用健康—数据库重启—完整回退—再次升级—应用重启序列、允许/禁止结果字段和精确资源清理；它不把一次演练冒充当前部署或服务器外备份。
